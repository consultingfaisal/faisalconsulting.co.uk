The measurement mistake that looks exactly like a performance problem

18 September 2026

A channel's numbers drop. The instinct is to treat it as a performance problem — the audience is fatigued, the creative needs refreshing, the budget should move elsewhere. Sometimes that's exactly right. Often, though, the real cause sits one layer back: something changed in how the activity is being measured, and the "drop" is an artefact of that, not of the campaign itself.

The tell: a sudden shift with no obvious cause

Genuine performance decline is usually gradual, or tied to something identifiable — a seasonal shift, a competitor move, creative fatigue building over weeks. A sharp, sudden change in reported numbers, especially one that lines up with a site release, a consent banner update, or a tracking change, points somewhere else entirely.

Consent changes quietly reshape the data

When a cookie consent setup changes — a new banner, a different default, a platform update to how consent is read — the pool of visitors being measured changes with it. Fewer tracked conversions can mean fewer real conversions, or it can mean the same number of real conversions with fewer of them visible to the tracking. These look identical on a dashboard and require different responses entirely.

A campaign change and a tracking change on the same date

If a new landing page went live in the same week the numbers moved, the honest next step is checking event firing on the new page before concluding anything about the campaign. It's a five-minute check that avoids weeks of optimising against the wrong problem.

Two people, two numbers, from "the same" report

If different people can pull what's meant to be the same report and get different figures, that's not a performance signal at all — it's a definition and ownership problem. No decision should be made from a number nobody can fully explain.

The check that settles it

Compare the platform-reported number against an independent source — CRM records, confirmed bookings, actual revenue — for the same period. If they've always disagreed by roughly the same margin, the drop is real. If the gap between them has changed, the problem is in the measurement, not the channel.

This is the exact distinction the Marketing Tracking QA Checklist is built to walk through before any budget decision gets made on the back of a number that might not mean what it looks like it means.
